# Superstore Sales Analysis Dashboard

## Project Overview

This project analyzes retail sales data from a Superstore dataset using Excel and Power BI.

The objective was to clean the data, perform exploratory data analysis (EDA), and build an interactive dashboard to identify sales trends, profitability drivers, regional performance, and business opportunities.

---

## Project Objectives

- Analyze overall sales and profit performance
- Identify high-performing and low-performing product categories
- Compare regional sales and profitability
- Evaluate the impact of discounts on profit
- Understand customer segment performance
- Create an interactive Power BI dashboard for business decision-making

---

## Tools Used

- Microsoft Excel
- Power BI
- DAX (Data Analysis Expressions)
- GitHub

---

## Dataset Information

The dataset contains **9,977 records** and **15 columns** including:

- Ship Mode
- Segment
- Country
- City
- State
- Region
- Category
- Sub-Category
- Sales
- Quantity
- Discount
- Profit

---

## Data Cleaning Process

Data cleaning was performed in Excel before importing into Power BI.

### Cleaning Steps

- Removed duplicate records
- Checked for missing values
- Standardized category names
- Corrected inconsistent text values
- Validated numerical columns
- Verified data quality before analysis

## Business Questions Answered

1. Which region generates the highest sales?
2. Which region generates the highest profit?
3. Which product categories drive revenue?
4. Which sub-categories generate losses?
5. How do discounts affect profitability?
6. Which customer segment contributes the most sales?

---

## Key Insights

- Regional performance varies significantly across the business.
- Certain product categories generate high sales but lower profitability.
- Excessive discounts can negatively impact profit margins.
- Customer segments contribute differently to overall revenue.
- Product-level analysis helps identify growth opportunities and loss-making areas.

---

## Business Recommendations

- Review discount strategies for low-margin products.
- Focus marketing efforts on high-performing categories.
- Improve inventory planning for profitable products.
- Investigate loss-making sub-categories for cost optimization.
- Expand successful product lines and regions.
